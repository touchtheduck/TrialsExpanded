# Trials Expanded

**A Minecraft mod that allows trial vaults and spawners to be mined and crafted**

![NeoForge](https://raw.githubusercontent.com/Hyperbole-Devs/vectors/8494ec1ac495cfb481dc7e458356325510933eb0/assets/cozy/supported/neoforge_vector.svg)

</div>

## Description

Trials Expanded is a Minecraft mod that allows trial vaults and spawners to be mined and crafted.
This mod adds new crafting recipes for (non-ominous) vaults and spawners, as well as a smithing template for upgrading vaults to ominous vaults.

Additionally, the vault upgrade smithing template can be found as loot in Vaults and Ominous Vaults with Ominous Vaults having a higher chance to drop it.
This vault upgrade smithing template can be copied like any other smithing template.

## Features

- Minable (Ominous) Vaults and Trial Spawners with silk touch
- Crafting recipes for Vaults and Trial Spawners
- Smithing template for upgrading Vaults to Ominous Vaults
- Vault Upgrade Smithing Template as Vault loot

Cutting Delight is currently only available for Neoforge. I'm currently not planning on porting this mod to other mod loaders.

I'm currently not planning on backporting this mod to earlier Minecraft versions than 1.21.1, but if you want you can try it yourself and open a pull-request on my github repository.
